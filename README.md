Diseño y desarrollo infraestructura de sistemas críticos desde cero (*from scratch*). Mi enfoque prioriza el rendimiento a nivel de metal, la predictibilidad operativa y la soberanía digital estricta mediante arquitecturas *zero-telemetry*.
